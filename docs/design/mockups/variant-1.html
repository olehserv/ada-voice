WPF fidelity notes

Everything in this variant translates 1:1. Colors are flat token brushes (same keys as today’s Tokens.Dark/Light.xaml); no gradients, no blur, no shadows beyond what WPF-UI already draws. The one addition over today’s app is the status pill (dot + ALL-CAPS label + tint), which design 09 already specifies — it restores an at-a-glance state signal instead of the 8 px dot inside the Start/Stop button. color-mix() hover tints shown here become pre-computed hover brushes in the token files. The red STOP is always filled when armed (playing) and quiet gray when idle — red is never decorative.
