WPF fidelity notes

Everything here translates, with three implementation notes. ① The state-lit window is two stacked Borders (each a LinearGradientBrush + the bloom RadialGradientBrush layer) cross-faded by Opacity over Motion.State — no brush animation, no shared-resource mutation, fully Storyboard-safe. ② Glows are DropShadowEffect ShadowDepth=0, used only on the LIVE pill, the recording dot, and STOP hover — maximum one glowing element per window at rest. ③ The gradient CTA (Brand.Gradient) needs a small ui:Button restyle because WPF-UI's Primary appearance generates solid accent brushes; Accent itself stays a SolidColorBrush for ApplicationAccentColorManager. The title-bar hairline is a 2 px Border with a LinearGradientBrush — the only place green and red meet. Tag scrim is denser in the light theme (#C2000000) so chip text holds 9.6:1 over white tiles. Implementation phases: docs/design/plans/brand-redesign-implementation-plan.md.
