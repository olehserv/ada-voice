WPF fidelity notes

Not 1:1, needs approximation: ① backdrop-filter: blur(14px) on panels — WPF has no per-element background blur. Approximate with the same low-alpha fills over the gradient window (shown colors already assume no blur), or switch the window to WindowBackdropType="Acrylic" (system blur, different look, currently None). ② CSS border-image gradient ring — in WPF this is actually easier: a Border.BorderBrush takes a LinearGradientBrush directly and keeps the corner radius (the CSS version loses it). ③ Glows are DropShadowEffect with ShadowDepth=0 — cheap at these sizes, but keep them off scrolling tiles except the single playing one. 1:1 safe: window LinearGradientBrush, radial bloom overlay (RadialGradientBrush on a decorative Border), gradient CTA (needs a small Button restyle since WPF-UI Primary generates solid brushes — see the architecture review), all animations listed above (Opacity/RenderTransform/Effect.Opacity only).
