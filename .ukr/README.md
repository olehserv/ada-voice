# AdaVoice

Локальний (local-first) десктопний застосунок для Windows для одного оператора, який цілий день повторює одні й ті самі фрази.

Вона записує фрази **один раз своїм власним голосом**, упорядковує їх і відтворює одним кліком
під час живих дзвінків. Аудіо маршрутизується так, що клієнт чує його, ніби вона сказала це у свій
мікрофон. Її справжній голос продовжує звучати між фразами, а одна клавіша миттєво зупиняє відтворення.

> **Сценарій використання:** онлайн-адміністратор/оператор на **дзвінках Zoho CRM у Google Chrome**, який
> дотримується повторюваних скриптів. AdaVoice — це інструмент для підвищення ефективності справжньої, присутньої людини, а не автоматизація дзвінків
> і не клонування голосу. Дивіться [нотатку про етику](#ethics--privacy) нижче.

робочого застосунку (production) поки що не існує.**

Єдине джерело актуального статусу — це **[handoff.md](handoff.md)**: читайте його першим.
Наступний реальний крок: запустити spike для Phase 0 проти справжнього дзвінка Zoho (це ворота go/no-go).

## Як це працює (основна ідея)

Windows не дає способу записати аудіо *у* мікрофон, тому AdaVoice використовує безкоштовний
віртуальний аудіодрайвер **VB-CABLE** як програмний "провід":

```
mic + phrase WAV --> AdaVoice (mix + duck) --> CABLE Input ==> CABLE Output --> Chrome / Zoho --> client
                                               (virtual loopback: looks like a mic)
```

Chrome вибирає **CABLE Output** як свій мікрофон. AdaVoice безперервно пропускає справжній мікрофон
наскрізь і домішує фразу, коли її запускають. Повне обґрунтування:
[design 02 — audio routing](docs/design/02-audio-routing.md).

## Технологічний стек

- **.NET 10 · WPF · C#** (MVVM через CommunityToolkit.Mvvm)
- **NAudio** (захоплення/відтворення через WASAPI, мікшування)
- **VB-CABLE** — віртуальний аудіопристрій (встановлює користувач; не можна вбудувати в застосунок — ліцензування)
- Метадані у **JSON** + аудіо у **WAV** (48 kHz моно), повністю **офлайн**, без хмари, без акаунтів

## Spike для Phase 0

Одноразовий консольний прототип, який тестує найризикованішу частину (passthrough mic→CABLE + домішування
фраз + ducking) на справжньому залізі, перш ніж буде написано будь-який production-код. Налаштування, інструкції
із запуску й тестова матриця — у **[spike/README.md](spike/README.md)**.

## Етика та приватність

- AdaVoice відтворює **попередньо записані фрази справжнього оператора, який присутній і веде
  розмову**. Один запуск = одне людське рішення. Жодних авто-відповідей, жодного запланованого чи
  безконтрольного відтворення.
- Він ніколи не захоплює бік клієнта в дзвінку.
- Усі записи лишаються **на машині** — жодних мережевих викликів, жодної телеметрії.

Деталі: [design 07 — risks, security & privacy](docs/design/07-risks-security.md).
