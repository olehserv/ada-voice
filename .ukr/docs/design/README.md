# AdaVoice — Проєктна документація

Проєктні документи для AdaVoice: локальний десктопний застосунок для Windows (WPF / .NET 10),
який дозволяє онлайн-операторці програвати заздалегідь записані фрази власним голосом у мікрофон
під час живих розмов із клієнтами (Zoho CRM Web у Google Chrome).

**Статус:** Фаза проєктування завершена, переглянута (eng review 2026-06-10, разом із незалежним
зовнішнім критичним оглядом). Кодом застосунку ще немає.

## Ключові рішення

**Канонічна таблиця рішень міститься в [01-overview.md §4](01-overview.md#4-confirmed-decisions-canonical)** —
цей розділ є лише коротким викладом. Стисло: VB-CABLE + вбудований mixer (Voicemeeter відрепетирувано
як план B у Фазі 0), Zoho CRM у Chrome з дротовою гарнітурою, налаштовуване притишення (ducking), `Pause`
як гаряча клавіша аварійної зупинки, інтерфейс UA/PL/EN застосовується після перезапуску, запис є
взаємовиключним з перебуванням в ефірі, і одні нетехнічні «ворота» — наглядовий пілот з операторкою після
Фази 3 (ворота дозволу роботодавця було знято 2026-06-13: угода не потрібна).
