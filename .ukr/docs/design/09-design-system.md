# AdaVoice — Дизайн-система

Єдине джерело правди для візуальних рішень. Екрани специфіковано в
[05-ui-design.md](05-ui-design.md); вони будуються з
токенів нижче. Встановлено design review 2026-06-10.

## Напрям

Спокійна, темна, нативна Windows-утиліта — класу OBS/Voicemeeter, а не SaaS-дашборд.
Найкращий дизайн тут невидимий: оператор перестає помічати, що застосунок існує.
Принцип віднімання за замовчуванням: якщо елемент не виправдовує свої пікселі під час дзвінка, прибрати його.

## Тема

- Бібліотека **WPF-UI** (стиль Fluent / Windows 11, MIT) — без саморобного chrome.
- **Фіксована темна тема** (перевага оператора; одна палітра, перевірена раз). Без світлого режиму,
  без слідування за системою у v1.

## Токени

| Token | Value | Use |
|---|---|---|
| `Surface.Window` | `#1F1F1F` | Тло вікна |
| `Surface.Raised` | `#2B2B2B` | Кнопки, панелі, rail |
| `Text.Primary` | `#F0F0F0` | Заголовки, основний текст |
| `Text.Secondary` | `#A0A0A0` | Тривалості, метадані, підказки |
| `Status.Live` | `#54D262` | Крапка + мітка LIVE |
| `Status.OffAir` | `#F2A33C` | Банер OFF AIR |
| `Status.Degraded` | `#FF6B6B` | Банер DEGRADED, кнопка STOP |
| `Accent` | `#4CC2FF` | Фокус, свічення при відтворенні, інтерактивні підсвічування — ощадливо |

Усі пари текст/поверхня мають тримати контраст ≥ 4.5:1. Кольори статусу перевірено проти
`#1F1F1F` і `#2B2B2B`.

## Типографіка

Segoe UI Variable (платформна конвенція). Розміри в DIP:

| Role | Size / weight |
|---|---|
| Заголовки вікна / секцій | 20 / 16 semibold |
| Заголовок кнопки фрази | 16 semibold, обрізання на 2 рядки + еліпсис, повний заголовок у tooltip |
| Рядок статусу | 14 ALL-CAPS |
| Метадані / тривалості | 12 |

Нижня межа: нічого нижче 12; елементи статусу ніколи нижче 14.

## Відступи і форма

- Сітка 4 px; кроки відступу контролів 8 / 12 / 16.
- Радіус кута 4 px скрізь — один радіус, без змішування.
- Кнопки фраз ≥ 96 px заввишки; усі інші інтерактивні цілі ≥ 32 px.

## Правила

- Кольори категорій з'являються **лише** як маленька крапка в rail категорій. Кнопки фраз лишаються
  нейтральними — без кольорових рамок чи тонування кнопок за категорією.
- Лише утилітарний текст: орієнтація, статус, дія. Без емоційного тексту. Локалізовано UA/PL/EN, розміром
  під найдовшу локаль.
- Один акцентний колір; декоративні градієнти, blobs, icon-circles та emoji-as-design
  заборонені.
- Два іменовані макети вікна (Full ≥ 720 px, Docked 420–719 px); мінімум 420 × 560;
  з урахуванням DPI на кожен монітор.
